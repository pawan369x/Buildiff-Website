# Buildiff Nutrition ⚡

> **Official Store & Sports Nutrition Platform**

Built with **React**, **Vite**, **Framer Motion**, and **Tailwind CSS**.

## ✨ Features
- **Official 3D Metallic Emblem**: High-tech chrome branding & sports nutrition aesthetics.
- **Creative Floating Navbar**: Spring layout physics, dynamic hover/active glow pills, mobile drawer.
- **High-Impact Hero Banner**: Clinical nutrition pillars, responsive metallic CTAs, and lab purity guarantees.
- **Interactive Cart & Store**: Cart state management, product catalog data, and checkout flow.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
